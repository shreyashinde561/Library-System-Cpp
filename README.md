# 📚 Library Management System (C++ OOP + File Handling)

## 📌 Overview
This is a console-based Library Management System built using C++.  
It demonstrates Object-Oriented Programming (OOP) concepts along with file handling for storing data permanently.

---

## 🚀 Features
- Add new books
- Display all books
- Search book by ID
- Delete book
- Issue book
- Save data to file (`data.txt`)
- Load data automatically on startup

---

## 🛠️ Technologies Used
- C++
- Object-Oriented Programming (OOP)
- File Handling (fstream)
- STL Vector

---

## 📂 Project Structure
LibrarySystem/
├── main.cpp        (menu system)
├── Book.h          (Book class)
├── Book.cpp        (Book functions)
├── Library.h       (Library class)
├── Library.cpp     (logic implementation)
├── data.txt        (stored data)
└── app.exe         (compiled file - not uploaded)

---

## ▶️ How to Run

### Compile
g++ main.cpp Book.cpp Library.cpp -o app.exe

### Run
./app.exe
